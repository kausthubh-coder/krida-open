Three choices for you

  1. Host leaves, nobody from their account left: the model ends the party. Today it passes to anyone, maybe without TorBox. End it?
  2. Host leaves, only guests left: the model ends it. Today guests keep watching on the host’s TorBox. End it?
  3. A room you’re invited to but not in: the spec lists its other accounts’ members; the model lists only yours. Change the spec?
